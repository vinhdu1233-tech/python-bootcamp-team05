## Pull Request Review Checklist

- [ ] The required exercise files are present.
- [ ] Functions match the assignment requirements.
- [ ] Code is readable and follows Python conventions.
- [ ] Edge cases are handled appropriately.
- [ ] Names, type hints, and docstrings are clear.
- [ ] Available tests or manual checks have been reviewed.
- [ ] AI usage is disclosed when required.
- [ ] Reviewer leaves at least one Question.
- [ ] Reviewer leaves at least one Suggestion.
- [ ] Reviewer leaves at least one Praise.
- [ ] Reviewer approves only after sufficient verification.

## Current Testing Limitation

The instructor has not yet provided the official Python Bootcamp tests.

Reviewers must clearly state which checks were completed and which remain pending.

## Review Process

1. The author opens a pull request.
2. The author requests the assigned reviewer.
3. The reviewer examines the changes and available checks.
4. The reviewer leaves constructive feedback.
5. The author addresses requested changes.
6. The reviewer approves when requirements are satisfied.
7. The pull request is merged.
